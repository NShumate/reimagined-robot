# Design Colors

This repository stores the approved color palette and usage notes for the brand system.

## AWS-aligned structure
- colors/approved/ for final palette files
- docs/ for color usage guidelines and examples

## Naming conventions
- Use clear names such as `primary-blue`, `accent-gold`
- Document hex, RGB, and CMYK values where appropriate
- Keep only finalized palette entries in the approved folder

## Notes
Document primary, secondary, and accent colors with hex values. Maintain a single approved source of truth for the palette.
