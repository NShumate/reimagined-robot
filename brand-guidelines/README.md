# Brand Guidelines

This repository stores the approved brand rules, standards, and supporting documentation for the organization.

## AWS-aligned structure
- docs/ for standards, usage guidance, and review notes
- assets/ for shared brand materials
- logos/ for approved logo files
- icons/ for approved icon sets

## Naming conventions
- Use lowercase, hyphenated names
- Keep file names descriptive and version-aware where needed
- Store only approved files in the main folders

## Notes
Keep brand standards, usage rules, and approved visuals here. Update this repository whenever the brand changes.
