# Approved Fonts

This repository contains the approved typefaces and font usage guidance for the brand.

## AWS-aligned structure
- fonts/approved/ for final font files
- docs/ for usage notes and licensing information

## Naming conventions
- Use descriptive names such as `brand-sans-regular.ttf`
- Keep font family names consistent
- Document licensing and approved usage in the docs folder

## Notes
List font names, licensing notes, and usage examples here. Keep this repository limited to approved assets.
