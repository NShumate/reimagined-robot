# Logos and Icons

This repository contains approved logo and icon assets for the brand.

## AWS-aligned structure
- logos/approved/ for final logo files
- icons/approved/ for final icon files
- docs/ for usage restrictions and size guidance

## Naming conventions
- Use descriptive names and version identifiers where needed
- Keep raster and vector files organized separately
- Avoid duplicate or draft assets in the approved folders

## Notes
Keep only final approved files here. Use the documentation folder to explain usage rules and restrictions.
