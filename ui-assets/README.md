# UI Assets

This repository contains reusable UI graphics and supporting assets for product and web experiences.

## AWS-aligned structure
- images/approved/ for final interface graphics
- icons/approved/ for reusable UI icons
- docs/ for guidelines and usage notes

## Naming conventions
- Keep UI asset names consistent and descriptive
- Separate final assets from working drafts
- Document any accessibility or size requirements

## Notes
Store reusable interface assets here for easy reuse across projects. Keep the content versioned and well documented.
